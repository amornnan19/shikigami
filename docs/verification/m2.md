## Gap filled

Check 8 had Rust tests and real-CLI probes but no e2e proof that the key reaches the CLI by the helper
and not by the environment. `auth-mode.e2e.ts` now runs a turn of an agent set to API key with a saved
key. The fake CLI (`e2e/fake-providers.ts`) records its `ANTHROPIC_API_KEY` and the output of the
`apiKeyHelper` named in its settings in `key.log`.
